# Calories Burn Prediction Using Machine Learning

## About the Project

This is my college project, in which I am developing a **Calories Burn Prediction System using Machine Learning**. The main goal of this project is to predict the number of calories burned during physical activity based on a person's health information and workout details.

I am using a dataset containing exercise and health-related information to understand the relationship between physical activity and calorie expenditure.

I have completed the dataset preprocessing and trained a Machine Learning model. I am now working on model evaluation, frontend integration, and testing to develop a complete application that allows users to predict their calorie expenditure.

## Dataset

I am using the **Calories Burnt Prediction Dataset from Kaggle**.

The dataset contains information related to exercise and physical activity, including:

* Age
* Gender
* Height
* Weight
* Duration of exercise
* Heart rate
* Body temperature
* Calories burned (target variable)

The dataset is used to train a Machine Learning model that predicts the number of calories burned based on the available input features.
